## Customer Lifetime Value (CLV)
A Customer Lifetime Value (CLV) can be defined as a measure of someone's total worth for an enterprise over the relationship duration.
Therefore, it also helps enterprises to decide what to invest to retain or gain new customers.

### The goal:
Predict the customer's lifetime value.

### Dataset: 
IBM Watson Marketing Customer Value Data (https://www.kaggle.com/datasets/pankajjsh06/ibm-watson-marketing-customer-value-data/data)
